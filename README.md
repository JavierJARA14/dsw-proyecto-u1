# dsw-proyecto-u1

Este avance consiste en la creación de la estructura base del proyecto final, implementando una API REST que incluye CRUD de usuarios y productos, además de endpoints iniciales relacionados al carrito de compras. Se integró Firebase Firestore, y se implementó autenticación mediante JWT para proteger rutas y validar la identidad de los usuarios.

## Funciones principales
- CRUD de usuarios (crear, leer, actualizar y eliminar)
- CRUD de productos almacenados en Firebase
- Autenticación con JSON Web Tokens (JWT)
- Estructura base del proyecto y rutas protegidas
